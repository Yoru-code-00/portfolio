# YORU Portfolio

個人ポートフォリオサイトです。WebデザイナーおよびWebプログラマーとしての実績・スキルを掲載しています。

**URL**: [yoru-code.com](https://yoru-code.com)

## 使用技術

- HTML / CSS / SCSS
- JavaScript（バニラJS）
- Google Fonts

## 主な機能

- スクロールアニメーション（フェードイン・スライドイン）
- スロットマシン風プロフィールアニメーション
- LOADINGグリッチアニメーション
- ハンバーガーメニュー（レスポンシブ対応）

## ページ構成

| セクション | 内容 |
|-----------|------|
| PROFILE | 基本情報・スキルゲージ・スロットアニメーション |
| SKILL | HTML/CSS/JS・WordPress・Figma |
| WORKS | 実績・制作物一覧 |
| CONTACT | お問い合わせフォームへのリンク |

## 制作実績（WORKS）

- 株式会社ケイ建設 About・Recruit ページ（コーディング）
- デモサイト（デザイン / コーディング）

## ローカルで動かす

```bash
git clone https://github.com/Yoru-code-00/portfolio.git
cd portfolio
# index.htmlをブラウザで開く
```
